# Hướng dẫn chạy Backend TypeScript (MCP + REST/Socket.IO)

### 1. Cài đặt các thư viện (BẮT BUỘC để hết lỗi Cannot find module):
```bash
npm install
```

### 2. Chạy MCP Server (Dành cho AI Agent / Claude / Antigravity):
```bash
npm run dev:mcp
```

### 3. Chạy REST API & Socket.IO (Dành cho Mobile App Flutter):
```bash
npm run dev:api
```

### 4. Build TypeScript sang JavaScript:
```bash
npm run build
```
